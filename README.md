# синтез на Yosys + Sky130

Задание по логическому синтезу. Взял передатчик, синтезировал через Yosys на Sky130 (hd библиотека, typical corner). Получил нетлист, площадь и sta (опционально).

## Файлы

- `counter.v` — исходный RTL
- `synth.ys` — скрипт синтеза
- `counter_out.v` — нетлист после синтеза
- `synth.log` — лог
- `build.sh` — установка окружения
- `images/` — svg-схемы модуля
- `sta.tcl` — скрипт для OpenSTA

## Как запускать

1. Поставить окружение (см. `build.sh` )

2. Найти путь к либе:
```bash
find ~/.volare -name "sky130_fd_sc_hd__tt_025C_1v80.lib" 2>/dev/null
```
И подставить путь в `synth.ys`.

4. Запустить синтез:
```bash
yosys synth.ys 2>&1 | tee synth.log
```

5. STA (опционально):
```bash
sta sta.tcl 2>&1 | tee sta.log 
```

6. Посмотреть картинки:
```bash
yosys -p "read_verilog counter_out.v; show -format png -prefix counter_schema counter"
```
   

## Результаты

Всего ячеек: 31 шт.

Площадь модуля (Chip Area): 329.0656 мкм² (точная физическая площадь геометрии ячеек, рассчитанная Yosys для базиса Sky130).

Количество триггеров: 8 шт. (использованы последовательностные ячейки sky130_fd_sc_hd__dfrtp_1 с асинхронным сбросом низким уровнем). 
Счётчик синтезирован как стандартный 8-битный двоичный счётчик. 

Комбинационная логика: 23 ячейки. 
Остальной базис схемы составляют инверторы (clkinv), логические элементы И (and2, and3, and4), ИЛИ-НЕ (nor2, nor3), элементы И-НЕ (nand4), а также сложные составные AOI/OAI-вентили (a21oi, a31oi, o21ai), которые Yosys оптимально подобрал для реализации логики инкремента, разрешения работы (en) и синхронного сброса (clr).

STA: setup slack +8.3400 нс, hold +0.0500 нс, всё MET. Запас по частоте большой.
